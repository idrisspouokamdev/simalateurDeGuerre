# SimalateurDeGuerre

Un simulateur de combat en JavaScript orienté objet.

## Description
Ce projet simule des affrontements entre différents personnages (Magicien, Guerrier) avec des attaques normales et des coups spéciaux. Chaque personnage possède un niveau, des points de vie et une puissance d'attaque. Le projet est réalisé en JavaScript pur (POO) et peut être exécuté dans un navigateur ou avec Node.js.

## Fonctionnalités
- Création de personnages (Magicien, Guerrier)
- Attaques normales
- Coups spéciaux
- Évolution de niveau après chaque attaque
- Vérification de la santé (mort du personnage)
- Affichage des informations en temps réel

## Technologies utilisées
- JavaScript (ES6)
- Programmation Orientée Objet (classes, héritage)
- Node.js (pour l'exécution en ligne de commande)
